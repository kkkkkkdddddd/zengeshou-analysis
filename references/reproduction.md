# 输入与复刻

## 图片到原表

用可用的本地查看器按行分段放大图片。确认表头、年份的连续性及列边界，再按 [输入模板](../assets/insurance_input.csv) 录入 UTF-8 CSV，保留数字、百分比和原图文字。多页表检查重复行和断行。原有空格留空，明确的零写 0。百分比使用 `6.12%` 或 Excel 的比例值。诸如「缴费期」的合并标注写在相应列首格，脚注用 `--note`。

输出前对照每一行，重点复核首末行、年金跳变、身故与生存情景、原图本来就存在的小额算术差异。对缺失的现金价值留空，无法计算的年龄不填造数据。

## 运行

需要 Python 3.10 或更新版本及 XlsxWriter，读 Excel 时加用 openpyxl。

```powershell
python -m pip install XlsxWriter openpyxl
python scripts/build_workbook.py "本地转录.csv" --output "保险分析.xlsx" --title "产品利益演示" --blank-events-zero --payout-age 78 --exit-age 62
```

- `--sheet` 选择来源 Excel 工作表，默认优先取「原图数据」，没有时取活动表。「年龄年末」与「年末年龄」兼容。
- `--payout-age` 指合同已确认或用户明确要求计算的末次生存给付年龄。该年取图示年金，无额外退保金及身故金；之后的原表年度仍完整保留。未设时，按末个有数值现金价值的年龄退保。
- `--exit-age` 设默认退保年龄，也可在 Excel 的「现金流与实际利率」B5 键入数值年龄。
- `--blank-events-zero` 将保费、年金或年度红利栏的空白按无收付处理，原表留空。已经确认的未知收付应先核对来源。
- `--roll-rate 0.023` 只用于检验某个明确标注的滚存假设，比较结果及残差保留在逐年表。它不进入现金流。
- `--note` 可重复添加原表注记。模板只有表头，无真实案例数据。

## 复核

时点 0 交首笔。期末领取可与下一年度首笔交费落在同一时点，提前退出时应停止下一年保费。退保与同年给付的先后及红利是否可领取须核对合同。逐年 IRR 的首年可手算，之后用现值归零复核。现金流多次变号时先检查情景，避免将任一求根值当作唯一年化。

翻倍按全表列出的总保费乘以二，比较名义金额。领取达标仅查看所选的给付或退保终点及以前。海报增长比例可能以累计保费为分母，同比以上年演示总额为分母，IRR 以逐笔收付和时间求解。保留原始的合计与增长字段，现金流用分项数值。

生成脚本只做本地文件 I/O。技能仓库仅含 `SKILL.md`、界面元数据、说明、空白 CSV 和生成脚本。用户原图、转录结果、Excel、个人信息与本机路径均不进入仓库。
